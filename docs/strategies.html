Strategies

Strategy groupings

01

Read-level classification and profiling

Assigns reads directly by k-mer, translated alignment, or marker/rRNA mapping and summarizes abundance. Fast classifiers and marker profiles are useful for community comparisons; taxon coverage and false positives depend strongly on database content and version. KAPTAIN is long-read and genome-reference based; MOCAT2 and MGnify use more curated marker/reference catalogs.

nf-core/taxprofiler bioBakery workflows wmgx HOME-BIO MOCAT2 MetaShot MGnify pipeline v5 KAPTAIN
02

Clinical and hypothesis-free mNGS

Searches broadly for candidate organisms in host-associated or surveillance specimens. CZ ID, RIEMS, and SURPI use broad nucleotide/protein references; TaxTriage adds alignment breadth, ambiguity checks, and evidence scoring; EDGE integrates configurable analyses and reports. Broad searches can be storage-intensive, and low-abundance calls require independent review.

TaxTriage CZ ID local short-read MNGS workflow EDGE Bioinformatics RIEMS SURPI
03

Assembly and genome-resolved identification

Assembles reads, predicts genes, then assigns taxonomy to contigs or recovered MAGs by homology or genome placement. These workflows provide genomic context but miss taxa that fail to assemble/bin; assembly, mapping, and binning intermediates can dominate disk and RAM. Their outputs are not equivalent to read-level abundance profiles.

SqueezeMeta nf-core/mag ATLAS MetaWRAP IMP Metagenomics-Toolkit
04

Untargeted viral metagenome workflows

Screens broadly within the viral domain, then assembles, validates, dereplicates, or annotates viral sequences. These workflows characterize viral genomes/community content but do not substitute for bacterial, archaeal, fungal, or general community profiling.

ViroProfiler VirMake nf-core/viralmetagenome metavirs

Pipeline similarity (PCA)

Each point is one pipeline and its name is printed beside the point. Principal components are calculated from four balanced feature blocks: tool presence/absence, supported taxonomic groups, intended taxonomic groups, and coarse workflow stages/methods. Tool features are not allowed to overwhelm the smaller taxa and methods blocks simply because there are more tools. Colors show the assigned strategy group; hover text contains only the pipeline name.

The PCA is exploratory: a pipeline’s position summarizes the encoded feature table, not benchmark performance or biological similarity. Its coordinates can change as tools, taxonomy evidence, and method annotations are updated.

Tool co-occurrence network

Each node is a distinct tool; node size reflects the number of included pipelines using it, and node color marks its broad purpose. Edge width is proportional to the number of pipelines containing that tool pair. The default threshold is two pipelines; lower it to one to show all pairs, or raise it to prune weaker associations. Tools with no visible edges at the selected threshold are hidden. Associations are pipeline-level co-inclusion, so optional alternatives listed by a workflow need not run together in one configuration.
