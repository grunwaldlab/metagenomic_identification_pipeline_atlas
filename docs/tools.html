RAM, database, results, and speed values are approximate planning ranges for a typical short-read sample (about 10 million paired 2x150 bp reads) where no directly comparable benchmark exists. Range columns display the source summary and sort by the largest numeric bound parsed in GB; the same bound drives cell shading. Qualitative descriptions use planning maxima (for example, “several GB” maps to 20 GB and “hundreds of GB” to 300 GB); N/R bounds sort as unavailable and remain uncolored. Speed uses an internal rank (Low < Low-Medium < Medium < High; N/A last in ascending order), not alphabetical order. Reference builds, settings, and retained intermediates can change these values substantially. Workflow engines and report generators are included but do not perform organism identification.

Pipeline count is the number of distinct included workflows mapped to the tool; the table defaults to highest count first.
